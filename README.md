## Jelly Lab — 푸른 유리젤리

차가운 연회색(`#EEF2F7`) 배경 위의 납작한 원기둥 젤리를 꼬집어 늘리는 Three.js 실험입니다.

- 맑은 푸른빛 재질, 내부 굴절, 부드러운 접지 그림자와 넓은 유광 반사
- 마우스 또는 터치로 작은 표면 부위를 잡아 길게 늘리기
- 손을 멈추면 잡은 끝점과 늘어난 상태 유지, 놓으면 점성 있게 복원
- 놓는 방향과 속도에 따른 튕김·회전, ‘툭 치기’로 뒤집기
- 한글 설정 패널: 질량감, 탄성, 내부 감쇠, 표면 매끈함, 느린 회전, 그림자
- 초기화 버튼은 모양과 움직임, 설정값을 기본값으로 복구합니다.

[공개 페이지](https://hanzizon.github.io/jelly-lab/)

## 실행

빌드 없이 정적 웹 서버로 실행할 수 있습니다. Python이 설치된 환경에서는 저장소 폴더에서:

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. Three.js 0.167.1은 unpkg CDN에서, 영문 제목 글꼴은 Google Fonts에서 불러오므로 인터넷 연결과 WebGL 지원이 필요합니다.

## 파일과 구현

- `index.html`: 제목과 한글 조절 패널
- `styles.css`: 연회색·블루 스타일, 모바일 배치
- `app.js`: HDRI 재질·조명, 원기둥 표면과 마우스·터치 입력
- `physics.js`: 405개 입자와 사면체 체적 제약을 사용하는 XPBD 젤리

120Hz 고정 간격으로 내부 거리·체적 제약과 바닥 충돌을 계산합니다. 잡힌 부위는 손 위치에 고정되고, 나머지 몸통은 중력과 관성에 따라 들리고 접힙니다. 놓으면 자유롭게 떨어지며 출렁이고 뒤집힙니다. 상대 속도 감쇠로 점성을 표현합니다. 터치 취소·창 전환 시 잡기를 해제하고 작은 화면은 픽셀 비율을 제한합니다.

체적 제약을 반복적으로 푸는 실시간 근사 모델입니다. 자기 충돌·광선 추적은 지원하지 않으므로 심하게 접으면 표면이 겹칠 수 있습니다. 가장자리의 짧은 광학 경로는 고정된 Three.js 버전의 재질 셰이더를 보완해 표현합니다.

GitHub Pages는 `main`의 루트 폴더에서 자동 배포합니다. 재질·스타일을 수정할 때 `index.html`의 파일 버전도 갱신해 캐시된 이전 화면을 방지합니다.
