# Jelly Jam

[공개 페이지](https://hanzizon.github.io/jelly-lab/)

로열블루 젤리를 잡아 늘리는 Three.js 실험입니다.

- 고양이 / 보컬 캐릭터 / DJ 캐릭터 선택
- 참조 사진을 재구성한 캐릭터 부조: 평평한 뒷면, 볼록한 앞면, 얼굴과 의상의 양각·음각
- 반대쪽 면을 먼저 그린 뒤 깊이 차이를 이용하는 투과 렌더링
- 창문 반사광, 내부 윤곽, 굴절되는 옅은 바닥선
- 포인터와 표면 보간으로 각진 늘어남 완화
- 기본 탄성 0.06, 내부 감쇠 0.95. 탄성을 높이면 더 늘어나고 출렁입니다.
- 놓았을 때 과한 속도와 이동 범위를 제한하고 프레임 저하에 따른 낙하 지연을 개선했습니다.

## 실행

빌드 없는 정적 사이트입니다. 정적 웹 서버로 실행하세요. 예: Python 설치 시 `python -m http.server 8000`.
Three.js 0.167.1은 unpkg, 제목 글꼴은 Google Fonts에서 불러옵니다.

## 파일과 검증

- index.html / styles.css: 제목, 한글 패널, 모양 선택, 모바일 배치
- app.js: 창문 조명, 양면 투과 렌더, 입력 및 표면 보간
- physics.js: 405개 입자와 사면체 체적·거리 제약
- shapes.js: 캐릭터 윤곽과 실제 부조 높이

15/30/60fps 낙하 시간, 세 모양의 잡기·놓기·바닥 충돌·이동 범위 및 입력 취소·초기화 검사를 수행했습니다.
캐릭터는 사진에서 직접 재구성한 근사 형태입니다. 자기 충돌이나 완전한 광선 추적은 지원하지 않습니다.

## 캐릭터와 화면 조절 업데이트

- 보컬 투과색 #162ae3, DJ 투과색 #3c458f. 기본 젤리와 같은 양면 투과 재질을 사용합니다.
- 모든 모양에 투과율 1.0의 동일한 렌더 경로, 둥근 부조 경계와 평평한 기본 뒷면. 잡거나 떨어지는 중에는 연성 물체로 함께 변형됩니다.
- 반사광 밝기 0~2.5, 확대 0.75~1.8. 확대는 젤리 중심을 향합니다.
- 내부 감쇠는 안정적인 고정값으로 유지하며 내부 감쇠·표면 매끈함 조절 UI는 제거했습니다.
- 높은 화면 픽셀 밀도, 원본 크기 굴절 버퍼와 4배 MSAA로 가장자리 품질을 개선했습니다.

- 기본 고양이는 참고 이미지의 얼굴·귀 외곽만 재구성한 비누 형태입니다. 눈·입·수염은 없으며 기존 원기둥과 높이(1.16)가 같습니다.

- 캐릭터 외곽을 넓은 가우시안 범위로 둥글게 다듬고 얼굴 부조 높이를 미리 평활화합니다. 뒷면의 기본 높이는 모든 지점에서 -0.58로 유지합니다.
