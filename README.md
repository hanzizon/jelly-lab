# Jelly Jam

[공개 페이지](https://hanzizon.github.io/jelly-lab/)

로열블루 젤리를 잡아 늘리는 Three.js 실험입니다.

- 고양이 / 보컬 캐릭터 / DJ 캐릭터 선택
- 참조 사진을 재구성한 캐릭터 부조: 평평한 뒷면, 볼록한 앞면, 얼굴과 의상의 양각·음각
- 반대쪽 면을 먼저 그린 뒤 깊이 차이를 이용하는 투과 렌더링
- 창문 반사광, 내부 윤곽, 굴절되는 옅은 바닥선
- 포인터와 표면 보간으로 각진 늘어남 완화
- 기본 탄성 0.06, 내부 감쇠 0.95. 탄성을 높이면 더 늘어나고 출렁입니다.
- 놓았을 때 과한 속도와 이동 범위를 제한하고 프레임 저하에 따른 낙하 지연을 개선했습니다.

## 실행

빌드 없는 정적 사이트입니다. 정적 웹 서버로 실행하세요. 예: Python 설치 시 `python -m http.server 8000`.
Three.js 0.167.1은 unpkg, 제목 글꼴은 Google Fonts에서 불러옵니다.

## 파일과 검증

- index.html / styles.css: 제목, 한글 패널, 모양 선택, 모바일 배치
- app.js: 창문 조명, 양면 투과 렌더, 입력 및 표면 보간
- physics.js: 405개 입자와 사면체 체적·거리 제약
- shapes.js: 캐릭터 윤곽과 실제 부조 높이

15/30/60fps 낙하 시간, 세 모양의 잡기·놓기·바닥 충돌·이동 범위 및 입력 취소·초기화 검사를 수행했습니다.
캐릭터는 사진에서 직접 재구성한 근사 형태입니다. 자기 충돌이나 완전한 광선 추적은 지원하지 않습니다.

## 캐릭터와 화면 조절 업데이트

- 보컬 투과색 #162ae3, DJ 투과색 #3c458f. 기본 젤리와 같은 양면 투과 재질을 사용합니다.
- 모든 모양에 투과율 1.0의 동일한 렌더 경로, 둥근 부조 경계와 평평한 기본 뒷면. 잡거나 떨어지는 중에는 연성 물체로 함께 변형됩니다.
- 반사광 밝기 0~2.5, 확대 0.75~1.8. 확대는 젤리 중심을 향합니다.
- 내부 감쇠는 안정적인 고정값으로 유지하며 내부 감쇠·표면 매끈함 조절 UI는 제거했습니다.
- 높은 화면 픽셀 밀도, 원본 크기 굴절 버퍼와 4배 MSAA로 가장자리 품질을 개선했습니다.

- 기본 고양이는 참고 이미지의 얼굴·귀 외곽만 재구성한 비누 형태입니다. 눈·입·수염은 없으며 기존 원기둥과 높이(1.16)가 같습니다.

- 캐릭터 외곽을 넓은 가우시안 범위로 둥글게 다듬고 얼굴 부조 높이를 미리 평활화합니다. 뒷면의 기본 높이는 모든 지점에서 -0.58로 유지합니다.

## 복원 및 바닥면 수정
- 잡기 제약을 화면과 동일한 곡면 보간으로 계산하여 별도 돌출 보정을 제거했습니다.
- 손을 놓으면 회전과 위치를 유지하면서 원래 전체 형상으로 복원합니다.
- 놓인 캐릭터의 뒷면 전체를 기울어진 상태에서도 하나의 평면으로 처리합니다. 잡고 변형하는 동안에는 젤리와 함께 변형됩니다.
- 세 모양 각각 3회 당기기·5초 복원 반복 검사와 실제 표면/잡기 지점 일치 검사를 통과했습니다.
`n복원 회귀 검사는 Node.js에서 `node tests/recovery.mjs`로 실행합니다.

## 낙하 및 뒤집힌 표면 수정
- 바닥 충돌 시 몸체 전체를 들어 올리던 처리를 제거하여 보정이 상승 속도로 누적되지 않게 했습니다.
- 표면의 부조 오프셋도 몸체와 함께 회전시켜 뒤집힌 뒤 남는 울퉁불퉁함을 수정했습니다.
- 중력 13.5와 공기 감쇠 0.55는 고양이 추가 이전 값입니다. 1.8 높이에서 낙하를 15/30/60fps로 확인했습니다(0.60/0.57/0.55초).
- 회귀 검사는 내부 입자뿐 아니라 실제 표시 곡면의 뒤집기·반복 당기기 후 잔여 변형도 검사합니다.

## 짧은 당기기 복원 수정
- 놓은 뒤 남는 내부 잔여 변형을 표면에 영구 반영하지 않고, 원래 곡면으로 연속적으로 이완합니다. 위치와 회전은 유지합니다.
- 다시 잡을 때 표시된 형상에서 시작하므로 숨은 찌그러짐이 되살아나지 않습니다.
- 양수 가중치의 곡면 보간과 잡힌 상태의 회전 갱신을 적용했습니다. 뒷면 평탄화도 놓는 순간 튀지 않도록 짧게 연결합니다.
- 이전 배포가 실패하는 1.2초 내 복원 기준을 적용하고, 세 모양·세 잡기 위치·세 번 반복 및 다시 잡기를 검사합니다.

## Chrome 성능 및 질량 반응
- 최종 화면은 CSS 픽셀당 최소 1픽셀을 유지하고 FXAA 후처리를 적용합니다. 글자와 패널은 후처리 대상이 아닙니다.
- 굴절용 보조 화면만 50~65% 해상도로 조절하며 2x MSAA로 경계를 처리합니다. 전체 화면을 70%로 낮추는 방식은 채택하지 않았습니다.
- 강제 확대 렌더와 전체 굴절 버퍼의 4x MSAA를 제거했습니다. 기기와 화면 크기에 따라 성능은 달라집니다.
- 질량은 툭 치기 충격, 놓을 때의 최대 속도, 바닥 마찰과 반발, 드래그 반응에도 적용합니다. 큰 질량은 적게 날고 덜 미끄러집니다. 중력은 18입니다.
- 동일 충격에서 고양이 상승 높이: 질량 0.3/1.25/1.8 각각 0.659/0.134/0.075. 세 모양에서 질량 순서와 복원을 검사합니다.
- 검증: node tests/recovery.mjs 및 node tests/mass.mjs.

## 잡아당길 때의 무게감 (stretch-13)
- 아래 안내 문구를 제거했습니다.
- 잡고 있는 동안 아래 방향의 하중을 질량에 맞춰 높이고, 잡은 주변의 변형 강도를 부드러운 분포로 조정했습니다. 자유 낙하 중력은 유지합니다.
- 동일한 1.5 단위 위쪽 드래그에서 몸통 상승량은 고양이 1.146→0.762, 보컬 1.339→0.726, DJ 1.270→0.876으로 줄었습니다.
- 내부 격자가 뒤집히려는 변형은 이전 안전한 상태 쪽으로 제한합니다. 한계를 넘는 당김에서는 잡은 지점이 떨어지지 않도록 몸통을 함께 이동합니다.
- `node tests/stretch.mjs`는 늘어남, 내부 격자 뒤집힘, 놓은 뒤 표면 복원을 검증합니다. `tests/recovery.mjs`와 입력 테스트도 통과했습니다.
- 화면 해상도와 FXAA는 유지합니다. Chrome 프레임은 실행 환경에 따라 편차가 있어 60fps를 보장하지 않습니다.

## 착지 반동 보완 (landing-15)
- 모양 복원 보정을 속도 계산에서 분리해 복원 자체가 위쪽 발사력으로 누적되는 현상을 줄였습니다.
- 바닥 접촉량과 질량에 따라 몸통의 위쪽 반동과 미끄러짐을 감쇠합니다. 국소적인 출렁임은 유지합니다.
- 세 모양의 옆으로 당기기 후 2~3초 착지 안정성, 질량별 반동, 반복 복원 및 늘어남 검사를 통과했습니다.

## 잡힌 상태의 출렁임 (held-wobble-16)
- 잡고 있을 때만 내부 감쇠를 낮춰, 손의 움직임이 늘어진 몸통으로 전달되고 관성에 따라 흔들리도록 했습니다. 놓은 뒤의 착지 감쇠는 유지합니다.
- 한 셀의 압축 때문에 몸통 전체가 멈추지 않도록, 압축된 내부 격자를 국소적으로 복구한 뒤 최후의 변형 제한을 적용합니다.
- 고정된 포인터 위치 상한을 제거했습니다. 안전한 늘어남 한계를 넘으면 손을 놓치지 않고 몸통이 함께 따라옵니다.
- tests/held-wobble.mjs: 잡은 채 손을 움직였다 멈췄을 때 몸통의 잔여 이동과 되튐을 세 모양에서 확인합니다.
- tests/held-motion.mjs: 늘린 채 위아래로 움직일 때 잡은 점과 몸통의 추종을 확인합니다.

- 바닥에 놓인 상태에서 잡으면 아래 방향 압축을 0.3 단위 이내로 제한합니다. 바닥을 뚫는 변형으로 큰 복원 반동이 생기지 않도록 했습니다.
- 공중에서 시작한 잡기는 이 압축 제한을 적용하지 않으며, 실제 바닥 충돌만 적용합니다.

- tests/down-pull.mjs에서 세 모양을 아래로 당겼다 놓은 뒤 상승량은 약 0.008 단위였습니다.

## 창문 반사광 (window-light-18)
- 밝기 슬라이더는 밝은 창문 반사 성분만 조절합니다. 뒷면 명암, 투명도, 코팅량, 바닥 그림자의 세기를 함께 바꾸지 않습니다.
- 표면의 반사 방향과 유한한 창문 평면의 교차점을 계산해 2×3 창틀 반사를 표시합니다. 표면이 변형되면 반사 형태도 따라 변합니다.
- 기본 밝기는 1이며, 화면 가장자리 보정과 기존 물리 동작은 유지합니다. 추가 장면 렌더링 패스는 없습니다.
- 밝기 0 / 2.5에서 반사 밝기만 바뀌고 코팅·뒷면 환경광 값은 고정되는 것을 입력 테스트로 확인했습니다.

## 사진 배경 (photo-floor-19)
- 설정의 배경 사진에서 JPG, PNG, WebP, AVIF를 선택할 수 있습니다. 기본 배경 버튼으로 회색 격자 바닥을 복원합니다.
- 사진은 기존 카메라 아래의 3D 바닥 평면에 배치되어 뒤쪽은 좁고 앞쪽은 넓어지는 원근감을 유지합니다. 젤리의 굴절과 바닥 그림자에도 같은 배경이 사용됩니다.
- 원본 비율을 유지하며 화면을 채웁니다. 가장자리가 일부 잘릴 수 있습니다. 화면 크기와 확대 변경 시 바닥 범위를 다시 맞춥니다.
- 선택한 파일은 서버에 전송하지 않으며 새로고침하면 해제됩니다. 표시용 이미지는 최대 2048픽셀로 줄이고 교체한 텍스처는 해제합니다.
- 원근 범위 계산(세 화면 비율, 두 확대 값), 선택/초기화, 지원하지 않는 파일 및 텍스처 해제를 자동 테스트했습니다. Chrome 확장 프로그램의 파일 접근 제한으로 실제 파일 선택의 시각 검증은 완료하지 못했습니다.

## 시야 각도와 사진 농도 (view-angle-20)
- 화면의 Jelly Jam 제목을 제거했습니다.
- 시야 각도 슬라이더는 30~60도(기본 45도)로 카메라를 젤리 중심 주위에서 회전시킵니다. 카메라 거리와 젤리의 물리 좌표는 바꾸지 않습니다.
- 사진은 불투명도 70%로 기본 바닥 위에 겹쳐 표시합니다. 각도/확대 전체 범위를 덮도록 배치해 시야를 기울일 때 사진 자체가 이동하지 않습니다.
- 카메라 중심/거리 고정, 젤리 좌표 유지, 사진 불투명도 및 바닥 범위 테스트를 통과했습니다. Chrome에서 각도 조절과 제목 제거를 확인했습니다.

## 보기·불투명도·사진 크기 (view-opacity-21)
- 시야 각도를 0~90도로 확장했습니다. 카메라 위쪽 방향도 함께 회전시켜 90도에서 뒤집히지 않습니다.
- 젤리 불투명도를 10~90%(기본 50%)로 조절합니다. 앞면과 뒷면의 알파에 반영하며 사진 배경 불투명도 70%와 독립적입니다.
- 확대와 시야각을 구분선 아래 화면 보기 영역으로 분리했습니다.
- 사진 크기는 25~200%(기본 100%)이며 젤리 아래 바닥 중심을 기준으로 확대·축소합니다. 작은 사진 주위에는 기본 바닥이 보입니다.
- 카메라 0/90도와 젤리 10/90%를 Chrome에서 확인했습니다. 사진 배치, 알파, 크기 비율 및 카메라/젤리 좌표 유지 테스트를 통과했습니다.

## 색상·탄산·접이식 설정 (appearance-22)
- 사진의 확대·축소 중심은 현재 젤리의 바닥 중심을 따라갑니다.
- 낮은 불투명도에서도 가장자리 반사 알파를 유지합니다. 설정 상단에서 색을 고를 수 있습니다.
- 기포는 젤리 내부 좌표를 따라 상승하고 커진 뒤 내부에서 터집니다. 투명한 중심, 흰 반사광과 어두운 테두리를 추가했습니다.
- 설정 창은 하단 버튼으로 접었다 펼칩니다. 모바일에서도 화면 아래에 접힙니다.
- 기포를 켜면 브라우저에서 합성한 작은 탄산 소리를 재생합니다. 탄산 소리 체크로 따로 끌 수 있고, 다른 탭으로 이동하면 멈춥니다.
- 세 모양의 입력/복원 및 사진 크기·중심·색상·기포 좌표 테스트를 통과했습니다. Chrome에서 기포와 접기 UI를 확인했습니다. 소리의 청감은 직접 검증하지 못했습니다.

## 움직임에 반응하는 탄산 (carbonation-23)
- 기포 상승을 물체의 로컬 축에서 월드 +Y로 변경했습니다. 현재 표면의 수직 교차 구간 안에서만 상승하며 회전해도 내려가지 않습니다.
- 기포를 18개로 줄이고 크기·생성 위치·상승 속도를 불규칙하게 분산했습니다. 큰 중앙 무리 대신 작은 기포가 전체에 나타납니다.
- 탄산 소리는 기본 무음이며 꼬집기, 끌기, 툭 치기에 반응해 약 0.05초에 커지고 이후 잦아듭니다. 기포 및 소리 옵션을 끄면 정지합니다.
- 0/90/180/270도 회전 상태의 월드 상승과 소리의 상승·감쇠 예약을 자동 검증했습니다. 기존 세 모양 입력 및 사진 테스트도 통과했습니다.

## 반응형 기포 (carbonation-24)
- 기본 기포 크기와 빈도를 유지하면서 흰 하이라이트와 테두리 대비를 더 높였습니다.
- 꼬집기·드래그·툭 치기에 반응해 최대 16개 추가 기포와 조금 큰 기포가 나타납니다. 손을 멈추면 추가 기포가 부드럽게 줄어듭니다.
- 소리와 기포는 같은 0.65초 감쇠 시간으로 잦아듭니다. 음소거 중에도 기포 반응은 유지됩니다.
- 기포 증가 후 기본 개수로 복귀, 4개 회전 각도에서 상승 방향 유지, 기존 입력·사진 테스트를 통과했습니다. Chrome 실행 오류가 없음을 확인했습니다.

## 기본색 복원과 홀로그램 (hologram-25)
- 색상 아래 기본색 버튼은 사용자 색과 무지개 효과를 해제하고 현재 모양의 기본색(고양이 #2f6bff, 보컬 #162ae3, DJ #3c458f)을 복원합니다.
- 무지개 버튼은 시야각·표면 법선·광원 반사 방향에 따른 색 변화 효과를 켭니다. 투명함과 창문 반사는 유지합니다.
- 사용자 색을 직접 고르면 단색으로 전환합니다. 무지개를 다시 끄면 선택했던 색으로 돌아갑니다.
- Chrome에서 무지개 렌더링, 보컬/DJ 기본색 복원과 사용자 색 변경을 확인했고 렌더링 오류가 없었습니다.

## 배경 조명 (lighting-26)
- 배경 조명에서 기본 창문빛, 다홍·주황 석양, 남색 별밤을 선택합니다.
- 석양은 주황 반사광, 별밤은 푸른 조명과 둥근 달빛 반사를 사용합니다. 별과 달은 원근 바닥에 절차적으로 그립니다.
- 사진 배경의 원근·불투명도와 색상/무지개 선택은 유지합니다. 조명 선택은 밝기나 모양을 바꿔도 유지됩니다.
- 세 테마의 색상/재질 전환과 기본 복원을 자동 검사했습니다. 브라우저에서 석양·별밤 선택 및 밝기 입력에 오류가 없었습니다. 이번 환경의 화면 캡처 실패로 최종 외관의 시각 검증은 제한됩니다.

## 야광과 창밖 풍경 반사 (night-glow-27)
- 별밤에서 젤리 몸통과 테두리에 푸른 발광 성분을 추가했습니다.
- 창문 반사 내부를 석양의 해와 주황 하늘, 별밤의 별과 달로 채웁니다. 반사는 표면 변형과 시야각을 따릅니다.
- 조명 전환 검사 및 브라우저 렌더링 오류 검사를 통과했습니다. 화면에서 해 반사와 야광을 확인했습니다.

## 쫀득함과 기포 수명 개선 (refinement-28)
- 잡은 지점 주변의 늘어남을 소폭 늘렸습니다. 기존 부피·접촉·복원 안전장치는 유지합니다.
- 새 기포는 0.18초 동안 자라며 나타나고, 상단에서 0.14초 동안 수축하고 작은 링으로 사라집니다. 한 프레임 만에 사라지는 현상을 완화했습니다.
- 큰 기포가 조금 더 빨리 올라가고 각 기포의 상승 속도가 미세하게 달라집니다. 월드 위쪽 방향은 유지합니다.
- 표면 탐색의 삼각형과 격자 배열을 재사용해 매 프레임 반복 메모리 할당을 줄였습니다. 프레임 향상 수치는 별도 측정하지 않았습니다.
- 세 모양의 반복 복원·늘어남·착지·아래 당김·잡은 상태 출렁임 검사 및 기포 상승/감쇠 검사를 통과했습니다.
- 롤백 기준: c4018babfbb560cff540b05b74aa58c873af379b.
